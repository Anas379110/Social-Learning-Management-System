# Social Learning Management System (LMS)
**Social Learning Management System (LMS)** · Classification: Full Stack

> Private client work — the source code is not public.

## Project Overview
LMS with courses, video streaming, quizzes, certificates, and live sessions.

## Highlights
- SignalR for real-time discussions and Q&A
- Azure Blob + CDN for video hosting
- PDF certificates with a points and badges system

## Role
Full Stack Developer: frontend, backend services, databases, and deployment.

## Technologies
Angular, ASP.NET Core, SQL Server, SignalR, Azure Blob, Azure CDN, Docker
