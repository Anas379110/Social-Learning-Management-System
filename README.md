# نظام إدارة التعلم الاجتماعي (LMS)
**Social Learning Management System (LMS)** · التصنيف: متكامل (Full Stack)

> هذا المشروع خاص بشركة/عميل محدد، والكود المصدري غير منشور.
> Private client work — the source code is not public.

## نبذة عن المشروع
LMS مع دورات، بث فيديو، اختبارات، شهادات، وجلسات مباشرة.

## أبرز النقاط
- SignalR للنقاشات والـ Q&A في الوقت الفعلي
- Azure Blob + CDN لاستضافة الفيديو
- شهادات PDF مع نظام نقاط وشارات

## الدور
مطوّر Full Stack: الواجهة الأمامية والخدمات الخلفية وقواعد البيانات والنشر.

## التقنيات المستخدمة
Angular, ASP.NET Core, SQL Server, SignalR, Azure Blob, Azure CDN, Docker
